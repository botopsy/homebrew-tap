# BotOpsy Homebrew tap

```sh
brew install botopsy/tap/hclaro
```

Builds [hclaro](https://github.com/botopsy/hclaro) from the tagged source archive (pinned by SHA-256) with Homebrew's Go. hclaro is in **beta**; see its [beta notes](https://github.com/botopsy/hclaro/blob/master/docs/BETA.md).

The binary is built on your machine and is not code-signed. Release archives, checksums and build-provenance attestations are on [GitHub Releases](https://github.com/botopsy/hclaro/releases).

The formula is maintained in [botopsy/hclaro](https://github.com/botopsy/hclaro/blob/master/packaging/homebrew/hclaro.rb) and updated here for each release ([process](https://github.com/botopsy/hclaro/blob/master/docs/RELEASING.md#homebrew-formula)). Report problems in the [hclaro repository](https://github.com/botopsy/hclaro/issues).
